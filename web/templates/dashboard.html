      Test kriterleri

      Hangi kontrolün ne aradığı.

      İşlevsellik

      API · WEB

      Beklenen yanıt geliyor mu, yanıt belgelenen şemaya uyuyor mu, geçerli bir form gönderilebiliyor mu?

      Sınır değerleri

      API · WEB

      Negatif sayılar, eksik zorunlu alanlar, yanlış tipte veriler ve var olmayan kayıtlar denenir.

      Güvenlik

      API · WEB

      Kimliksiz veya geçersiz token ile yapılan işlemler, yansıyan XSS ve eksik güvenlik başlıkları aranır.

      Yanıt süresi

      API · WEB

      Yalnızca okuma isteklerinin süresi eşikle (varsayılan 500 ms) karşılaştırılır.

      Web doğrulama

      WEB

      Kırık bağlantılar ile eksik görsel, script ve stil dosyaları bulunur. Web taramasında yalnızca aynı alan adındaki sayfalar gezilir.

      Sonuçları okumak

      Bulgular risk seviyesine göre gruplanır; en acil olan en üsttedir.

      CRITICAL

      Hemen düzeltin. Sunucu çöküyor (HTTP 5xx) ya da kimlik doğrulaması olmadan yıkıcı bir işlem yapılabiliyor.

      HIGH

      Önce bunlar. Geçersiz girdiler kabul ediliyor, XSS açığı var.

      MEDIUM

      Planlı olarak ele alın. Yavaş yanıtlar, belgeyle uyuşmayan cevaplar, kırık bağlantılar.

      LOW

      İsteğe bağlı. Eksik güvenlik başlıkları ve muhtemel yanlış alarmlar (ör. uydurma bir kimlikle alınan 404).

      Hatanın kaynağı

      Hatanın türü ve sistemin hangi tarafında olduğu, ör. "Eksik girdi doğrulaması · Sunucu tarafı".

      Nerede

      Değiştirilmesi gereken tam yer, ör. "POST /orders işleyicisi · alan: quantity".

      Tavsiyeler

      Sonuçların üstünde, hatalar kaynağa göre gruplanır ve her grup için genel bir öneri verilir.

          Raporu e-postayla gönder

          Bir testin sonuçlarını özet olarak e-postayla paylaşın. Alıcı "Raporu görüntüle" düğmesiyle HTML raporu açabilir; rapor e-postaya ek olarak da konur.

          E-posta gönderimi henüz ayarlanmamış.

          Proje klasöründeki .env dosyasına e-posta sunucunuzun bilgilerini yazıp paneli yeniden başlatın. Gmail örneği:

          BUGHUNTER_SMTP_HOST=smtp.gmail.com
BUGHUNTER_SMTP_PORT=587
BUGHUNTER_SMTP_USER=adresiniz@gmail.com
BUGHUNTER_SMTP_PASSWORD=uygulama-sifresi
BUGHUNTER_SMTP_FROM=adresiniz@gmail.com

          Gmail'de normal şifre çalışmaz; Google hesabı → Güvenlik → "Uygulama şifreleri" bölümünden 16 haneli bir şifre oluşturun.

          Henüz test yok. Önce "Testler" bölümünden bir test çalıştırın.
